# SPEC-PLAT-01: API contracts, architecture rules, end-to-end smoke test
- **Requirements:** NFR (maintainability, security), ADR-001 (hexagonal services), ADR-013 (no ORM), convention 6 (contract-first)
- **Status:** Implemented (agreed 2026-11-15; build green, smoke 17/17 PASS on the local stack)
- **Owner:** gc-backend (all services)

## 0. Decisions to agree
| # | Decision | Alternative |
|---|---|---|
| D1 | OpenAPI is generated by springdoc. `/v3/api-docs` and Swagger UI are **enabled only in the `local` profile**; production keeps them off (contracts move to `gc-contracts` later) | Always on (exposes the internal API surface) |
| D2 | A test exports each service's OpenAPI to **`gc-backend/contracts/<service>.openapi.json`** (committed). CI fails when the export differs from the committed file, which is contract drift | No committed contract (drift goes unnoticed) |
| D3 | Running case-service locally migrates **all 128 shard schemas once** (persisted in the Docker volume; ~4 min, parallelism 2, shard DDL serialised). Tests keep the light database | A "light local" mode with fewer shards (faster, but local ≠ production shape) |
| D4 | The smoke test is a **bash script** (`gc-backend/local-dev/smoke.sh`, curl + jq-free parsing via python) against the real stack: Docker (Postgres, Redis, Keycloak) + both services running with profile `local` | A Java/Testcontainers E2E suite (heavier on this laptop) |
